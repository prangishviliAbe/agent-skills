## ვიზუალური ხარისხის წესი

AI slop არის „საშუალო“: პირველი განლაგება, პალიტრა, ფონტი და წინადადება, რომელიც თავში მოდის, სწორედ ის არის, რაც ყველა სხვა გენერირებულ გვერდზე უკვე დგას. დიზაინის სქილები ორ რამეს ითხოვს ერთდროულად: **გადაწყვეტილებას** (ყველა default იცვლება არჩევანით, რომელიც ამ პროდუქტიდან, აუდიტორიიდან და შიგთავსიდან გამომდინარეობს) და **დასრულებას** (ეკრანზე არცერთი დეტალი არ რჩება განუხილველი).

აკრძალულია, თუ მომხმარებელმა ზუსტად ეს არ მოითხოვა:

- **სტრუქტურა:** ჰერო „ბეჯი + გიგანტური სათაური + ორი ღილაკი + ლოგოების რიგი“, სამი ერთნაირი „აიქონი–სათაური–ორი ხაზი“ ქარდი, შაბლონური სექციების თანმიმდევრობა, ქარდი ქარდში, bento ნაგულისხმევად.
- **ტიპოგრაფია:** გრადიენტიანი ტექსტი, ერთი დახრილი serif სიტყვა sans სათაურში, uppercase eyebrow ყველა სათაურზე, ცენტრირებული აბზაცები, დაბალკონტრასტული ან წვრილი ტექსტი.
- **ფერი:** იისფერი/ინდიგო და blue→pink გრადიენტები, ფრეიმვორქის default პალიტრა, ნეონი შავ ფონზე, ფერადი glow-ები და ჩრდილები.
- **ზედაპირები:** glassmorphism, gradient border, border beam, აქცენტის ზოლები, blob/aurora/mesh ფონები, dot grid, grain, ერთნაირი დიდი radius და ჩრდილი ყველა ყუთზე.
- **კომპონენტები:** ფერადი icon bubble-ები, დეკორატიული pill ბეჯები და წერტილები, ყალბი სტატუსის LED-ები, ყალბი ბრაუზერის ჩარჩო, გამოგონილი რიცხვები, რეიტინგები და ავატარების გროვა, sparkle აიქონი AI-სთვის, emoji აიქონებად.
- **ტექსტი:** „unlock“, „supercharge“, „seamless“, „effortless“ და მათი ქართული კალკები („გახსენით პოტენციალი“, „აიყვანეთ ახალ დონეზე“), გამოგონილი მიმოხილვები, მომხმარებლები და მეტრიკები, „Get started / Learn more“.
- **მოძრაობა:** fade-up ყველა ბლოკზე, hover scale ყველა ქარდზე, bounce, count-up, typewriter, უსასრულო loop-ები, scroll hijacking.
- **გამოსახულება:** 3D blob-ები და gradient orb-ები, stock ხელის ჩამორთმევები, ყალბი დეშბორდი ჰეროში.

„მეორე რიგის slop“-იც აკრძალულია: იისფერი გრადიენტის ჩანაცვლება კრემისფერი ფონით, serif-ით და ტერაკოტით იგივე შაბლონია სხვა ფერებში. მიმართულება მხოლოდ მაშინ ითვლება, როცა თემიდან გამომდინარეობს.

ფუნქციური ნიშნები რჩება: წარწერიანი სტატუსი, გრაფიკის სერიები, რუკის წერტილები, ფოკუსის რგოლი, არჩეული მდგომარეობა, პროგრესი, საჭირო გამყოფები და მშვიდი კონტეინერის საზღვარი. დამტკიცებული ბრენდი (ლოგო, ფერები, ფონტები) შეზღუდვაა და არა შესაცვლელი რამ.

`anti-ai-slop-design`-ს მოყვება სკანერი, რომელიც კოდში slop-ის ნიშნებს პოულობს:

```bash
node anti-ai-slop-design/scripts/slop-scan.mjs path/to/src
```

სკანერი კანდიდატებს აჩვენებს და არა განაჩენს; სუფთა შედეგი კარგ დიზაინს არ ამტკიცებს. ხარისხი დასტურდება რენდერით: რეალური შიგთავსი, ჩატვირთული ფონტები, ვიწრო/საშუალო/ფართო ზომები და ყველა მდგომარეობა. „pixel-perfect“, „fully responsive“ და „120fps“ დაპირებები შემოწმების გარეშე არ იწერება.

ქართული ტექსტი მოწმდება რეალური ფონტით (ქართული გლიფების დაფარვა ყველა გამოყენებულ წონაში), ნულოვანი letter-spacing-ით საწყისად, uppercase ტრანსფორმაციაზე დაყრდნობის გარეშე და ყველაზე გრძელი რეალური წარწერებით.

## სტრუქტურა

თითოეული საქაღალდე დამოუკიდებლად მუშაობს:

```text
skill-name/
  SKILL.md
  agents/openai.yaml
  references/
  scripts/        # არასავალდებულო; მაგ. anti-ai-slop-design/scripts/slop-scan.mjs
```

მთავარი ინსტრუქცია აჩვენებს, როდის უნდა წაიკითხოს აგენტმა კონკრეტული reference. სქილებს ერთმანეთის საქაღალდეებზე დამოკიდებულება არ აქვთ. ავტომატური არჩევა ჩართულია.

## ინსტალაცია

```bash
git clone https://github.com/prangishviliAbe/agent-skills.git
cd agent-skills
```

macOS / Linux:

```bash
./install.sh                 # Codex-specific folder
./install.sh claude
./install.sh antigravity
./install.sh all
./install.sh ./my-skills
./install.sh all --dry-run
```

PowerShell 7.2+:

```powershell
.\install.ps1
.\install.ps1 claude
.\install.ps1 antigravity
.\install.ps1 all
.\install.ps1 D:\my-skills
.\install.ps1 all -DryRun
```

უკვე გამოყენებული საერთო გლობალური საქაღალდისთვის მიუთითე ზუსტად ის ადგილი, საიდანაც შენი აგენტი სქილებს კითხულობს:

```powershell
.\install.ps1 (Join-Path $HOME '.agents/skills')
```

ინსტალატორები ჯერ ყველა ახალ სქილს staging-ში კოპირებს და შიგთავსს ამოწმებს. შემდეგ მხოლოდ ამ ექვსი სქილის ძველი საქაღალდეები ჩანაცვლდება მთლიანად, მოძველებული ზედმეტი ფაილების ჩათვლით. სხვა სქილები და სისტემური ინსტრუმენტები შენარჩუნდება. ძველი ასლები გადადის აქტიური სქილების საქაღალდის გარეთ, `.agent-skills-backups/`-ში; შეცდომისას ხდება აღდგენის მცდელობა.

Windows-ზე `update-skills.ps1` აკეთებს pull-ს და განაახლებს შესაბამის ადგილობრივ runtime-ებს, მათ შორის `.agents/skills`-ს. Codex-ის ცალკე საქაღალდისთვის ითვალისწინებს `CODEX_HOME`-ს.

```powershell
.\update-skills.ps1 -DryRun
.\update-skills.ps1 -Only agents
.\update-skills.ps1 -SkipPull
```

Codex განახლებულ სქილებს შემდეგ user turn-ზე აღმოაჩენს. სხვა runtime-ში ხელახლა გახსენი სესია, თუ სქილების სია დაკეშილია.


## შემოწმება

```bash
npm ci --ignore-scripts
npm run check
```

შემოწმება მოიცავს frontmatter-ს, metadata-ს, attribution-ს, თვითკმარ რესურსებს, ბმულებს, კოდის ბლოკების ფორმატს და ორივე ინსტალატორის ჩანაცვლების/აღდგენის სცენარებს. ავტომატური ვალიდაცია არ ამტკიცებს აგენტის დიზაინის ხარისხს ან უსაფრთხოებას.

ავტორინგის წესებია [AGENTS.md](AGENTS.md), შეფასების პროცედურა — [tests/evals/README.md](tests/evals/README.md).
