## ვიზუალური ხარისხის წესი

AI slop დეკორაციები აკრძალულია: ფერადი წერტილები სათაურებთან ან ქარდებზე, ყალბი სტატუსის LED-ები, ზედა/გვერდითი აქცენტის ზოლები, მოკლე ორნამენტული ხაზები, gradient outline-ები, მოძრავი border beam-ები, განმეორებადი icon bubble-ები, glow blob-ები და შიგთავსთან დაუკავშირებელი ფონის პატერნები.

ფუნქციური სტატუსები, გრაფიკისა და რუკის წერტილები, ფოკუსის ნიშნები, პროგრესის ინდიკატორები, საჭირო ცხრილის გამყოფები და მშვიდი კონტეინერის საზღვრები ინარჩუნებს თავის როლს. გამონაკლისია მომხმარებლის მიერ კონკრეტულად მოთხოვნილი ან დამტკიცებული ბრენდის მოტივი; ეს სხვა დეკორაციების დამატების უფლებას არ ქმნის.

UI/UX-ის ხარისხი ფასდება ტიპოგრაფიით, იერარქიით, განლაგებით, პროპორციებით, რეალური შიგთავსის მორგებითა და ეკრანზე შემოწმებით. არც glassmorphism, არც bento grid, არც ასიმეტრია და არც დამატებითი ეფექტები არ არის ავტომატური მოთხოვნა.

ქართული და ინგლისური ტექსტი მოწმდება რეალური ფონტითა და რეალური გადატანებით. ფიქსირებული პროცენტული „კომპენსაცია“ და დაუსაბუთებელი „pixel-perfect“ ან „120fps“ დაპირება არ გამოიყენება.

## სტრუქტურა

თითოეული საქაღალდე დამოუკიდებლად მუშაობს:

```text
skill-name/
  SKILL.md
  agents/openai.yaml
  references/
```

მთავარი ინსტრუქცია აჩვენებს, როდის უნდა წაიკითხოს აგენტმა კონკრეტული reference. სქილებს ერთმანეთის საქაღალდეებზე დამოკიდებულება არ აქვთ. ავტომატური არჩევა ჩართულია.

## ინსტალაცია

```bash
git clone https://github.com/prangishviliAbe/agent-skills.git
cd agent-skills
```

macOS / Linux:

```bash
./install.sh                 # Codex-specific folder
./install.sh claude
./install.sh antigravity
./install.sh all
./install.sh ./my-skills
./install.sh all --dry-run
```

PowerShell 7.2+:

```powershell
.\install.ps1
.\install.ps1 claude
.\install.ps1 antigravity
.\install.ps1 all
.\install.ps1 D:\my-skills
.\install.ps1 all -DryRun
```

უკვე გამოყენებული საერთო გლობალური საქაღალდისთვის მიუთითე ზუსტად ის ადგილი, საიდანაც შენი აგენტი სქილებს კითხულობს:

```powershell
.\install.ps1 (Join-Path $HOME '.agents/skills')
```

ინსტალატორები ჯერ ყველა ახალ სქილს staging-ში კოპირებს და შიგთავსს ამოწმებს. შემდეგ მხოლოდ ამ ექვსი სქილის ძველი საქაღალდეები ჩანაცვლდება მთლიანად, მოძველებული ზედმეტი ფაილების ჩათვლით. სხვა სქილები და სისტემური ინსტრუმენტები შენარჩუნდება. ძველი ასლები გადადის აქტიური სქილების საქაღალდის გარეთ, `.agent-skills-backups/`-ში; შეცდომისას ხდება აღდგენის მცდელობა.

Windows-ზე `update-skills.ps1` აკეთებს pull-ს და განაახლებს შესაბამის ადგილობრივ runtime-ებს, მათ შორის `.agents/skills`-ს. Codex-ის ცალკე საქაღალდისთვის ითვალისწინებს `CODEX_HOME`-ს.

```powershell
.\update-skills.ps1 -DryRun
.\update-skills.ps1 -Only agents
.\update-skills.ps1 -SkipPull
```

Codex განახლებულ სქილებს შემდეგ user turn-ზე აღმოაჩენს. სხვა runtime-ში ხელახლა გახსენი სესია, თუ სქილების სია დაკეშილია.

## შემოწმება

```bash
npm ci --ignore-scripts
npm run check
```

შემოწმება მოიცავს frontmatter-ს, metadata-ს, attribution-ს, თვითკმარ რესურსებს, ბმულებს, კოდის ბლოკების ფორმატს და ორივე ინსტალატორის ჩანაცვლების/აღდგენის სცენარებს. ავტომატური ვალიდაცია არ ამტკიცებს აგენტის დიზაინის ხარისხს ან უსაფრთხოებას.

`tests/evals/` შეიცავს დამოუკიდებელი ქცევითი შეფასების სცენარებს და ჩატარებული შეფასებების ჩანაწერებს. ახალი სცენარის დამატება მის შესრულებას არ ნიშნავს. შემოწმების სტატუსებია **Verified**, **Inferred**, **Assumed** და **Not run**.

ავტორინგის წესებია [AGENTS.md](AGENTS.md), შეფასების პროცედურა — [tests/evals/README.md](tests/evals/README.md).
