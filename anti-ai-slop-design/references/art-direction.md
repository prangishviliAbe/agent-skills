# Art direction from the subject

Read when: Starting a new design, or refining one broadly enough that its direction is open.

A direction is a short set of decisions that could only have been made for this subject. It is not a style name. "Modern minimal SaaS", "editorial", "brutalist", and "dark premium" are templates; choosing one of them is choosing a default.

## 1. Collect the brief

Fill this from the artifact and the conversation. Ask only for what blocks the work; mark the rest Assumed and continue.

```text
Subject:        what it is, in one plain sentence
Audience:       who arrives, in what situation, on what device
One job:        the single thing they must do or understand
Fixed:          logo, colors, fonts, layouts, system, legal text
Real material:  content, photos, data, screenshots that exist today
Tone:           three words that each exclude something
Not:            what this must never be mistaken for
```

Tone words must exclude. "Modern, clean, professional" excludes nothing and describes every generated page. "Blunt, archival, quick" or "warm, slow, hand-made" rule things out, which is what makes them useful.

## 2. Mine the subject's world

The material for a distinct design already exists in the subject. Look there before looking at other websites.

| Source | What to take from it |
| --- | --- |
| The trade's own documents: waybills, tickets, labels, menus, receipts, charts, blueprints, forms | Structure, hierarchy, numbering, tabular rhythm, stamp and field conventions |
| Tools, materials, and objects | Color drawn from real things, proportion, texture only if it is the real material |
| Signage, wayfinding, packaging, uniforms | Type attitude, color coding that already carries meaning |
| Place: geography, architecture, light, alphabet | Palette, imagery, script-led typography |
| Vocabulary and jargon | Headings, labels, navigation words nobody else uses |
| The data the product produces | The hero: real numbers, routes, timelines, statuses |
| The gesture of use: scanning, comparing, booking, tracking | Layout and density |
| History and heritage, if true | Type choice, tone, archival imagery |

Take structure and logic, not costume. A cargo site borrows the waybill's field grid and code typography; it does not paste a cardboard texture behind the page.

## 3. Write the thesis and the signature

```text
Thesis:     <who> needs to <job>; so the page <structural decision>,
            set in <type decision>, colored by <palette source>,
            and shows <real material> as its main image.
Signature:  the one element a visitor would describe afterwards.
Refused:    the defaults this direction rules out.
```

The signature is one thing, done with conviction: an oversized tracking-code lookup as the hero, a price table set like a timetable, a full-bleed photograph of the actual workshop, a route drawn across the page, a headline in the brand's own alphabet at monumental size. Everything else stays quiet so the signature can be heard. A page with five signatures has none.

## 4. Generate three, then choose

Sketch three options in words before building. They must differ in structure, not in color.

```text
A. Tool first:      the lookup or booking control is the hero; marketing follows below.
B. Evidence first:  one large real image or data figure; a single paragraph; one action.
C. Document first:  the page is set like the trade's own document, read top to bottom.
```

The first option that comes to mind is the most probable one, which is the definition of generic. Compare it honestly with the other two. Choose the one that best serves the job and can be executed with the material that really exists. A direction that depends on photography nobody has is not a direction.

## 5. Match the register

| Surface | What character means here | What it never means |
| --- | --- | --- |
| Marketing and brand pages | Strong composition, large type, real imagery, a point of view | Effects, ornament, invented proof |
| Product and tool UI | Density, legibility, exact alignment, a considered data style, fast feedback | Novel navigation, decorative layout, large empty heroes |
| Documentation and editorial | Reading comfort, clear structure, useful figures | Marketing chrome around the text |
| Commerce | The product seen clearly, price and availability unmissable, short path to buy | Lifestyle filler in front of the product |

In product UI, restraint is the direction. Familiar controls stay familiar. Personality goes into typography, color roles, spacing, wording, and the design of the data itself.

## Worked example: freight forwarder, Georgian and English

```text
Subject:    Freight forwarding from Europe and China to Georgia.
Audience:   Small importers checking where a parcel is, mostly on phones.
One job:    Find a shipment by its code.
Fixed:      Purple logo and brand purple.
Material:   Real tracking data, route list, tariff table, warehouse photos.
Tone:       Direct, exact, unhurried.
Not:        A logistics-startup landing page.

Default refused:  centered hero with badge and gradient headline, three icon cards
                  ("Fast", "Reliable", "Secure"), stats row, testimonial slider.

Thesis:     Importers need to find a shipment; so the page opens on the lookup field
            itself at full width, set in a Georgian-first sans with tabular figures,
            on warm paper-white with the brand purple reserved for the action and the
            current route leg, and shows a real shipment timeline as its main image.
Signature:  The tracking code, set large in tabular figures like a stencilled
            container number, with the route timeline directly beneath it.
Structure:  Lookup; live example result; tariff table set like a timetable;
            warehouse addresses as a plain list; contact.
```

Nothing in that result is decorated, and none of it could be moved to a different company without rewriting it. That is the swap test passing.

## Worked example: dental clinic

```text
Default refused:  smiling stock family, teal gradient, "Your smile, our passion",
                  icon cards for services.
Thesis:     Anxious people need to book and know the price; so the page leads with
            next available times and a real price list, set in a calm humanist sans,
            in the clinic interior's own colors, with photographs of the actual rooms
            and dentists.
Signature:  A price list as legible as a good menu, with nothing hidden.
```

## Using references

Study references for how they solve hierarchy, pacing, and density. Do not copy a competitor's assets, identity, or exact composition. Prefer references from outside the category: printed timetables, museum labels, instrument panels, well-set books, and packaging teach more than another landing page. A reference from the same category pulls the result back toward the category average.

## When the direction is fixed

If brand and system are given, the direction step shrinks to: what is the signature within these constraints, and which defaults in the current execution can be replaced with decisions. An approved purple and a centered hero can still become distinct through content, typesetting, and what is shown.
