# Diagnosing generic decisions

Read when a composition feels interchangeable, overdecorated, or disconnected from its content. These are diagnostic prompts, not a style blacklist or an AI-authorship detector.

Keep a common pattern when it serves the task. Refine it when execution is weak. Replace it when the underlying decision is wrong.

## Structure and composition

| Pattern to inspect | Actual failure signal | Possible correction |
| --- | --- | --- |
| Centered hero, two CTAs, product image | Vague promise, unclear next step, uninformative mockup | Sharpen the claim, action hierarchy, or product evidence; keep centering if it fits |
| Equal card grid | Content has unequal priority but every item receives equal emphasis | Lead with the consequential item; retain equal cards for comparable choices |
| Repeated section template | Repeated claims and no narrative progression | Consolidate redundancy and vary composition where content changes |
| Everything in containers | Boundaries add noise without clarifying independent objects | Group with proximity/type, simplify nesting, or keep boundaries where comparison needs them |
| Full-width prose | Lines are difficult to track at the actual font/viewport | Constrain reading measure while allowing media/data to use space |
| Large empty regions | Key information is delayed without pacing or brand benefit | Tighten rhythm or add meaningful content; preserve intentional breathing room |
| Forced asymmetry | Reading order or task comparison becomes harder | Restore a clear alignment/grid and put expression elsewhere |

## Color and surfaces

| Pattern to inspect | Actual failure signal | Possible correction |
| --- | --- | --- |
| Purple/blue or another familiar gradient | Palette ignores brand, carries no chosen mood, or weakens contrast | Use the approved palette and tune placement/contrast; preserve a purposeful gradient |
| Glass/translucent panels | Variable backgrounds make text or controls unreliable | Add a stable backing, adjust opacity/blur, or use solid surfaces |
| Glow and blurred shapes | Competing focal points, poor text contrast, costly rendering | Reduce competing effects, simplify treatment, or remove the unnecessary layer |
| Dark canvas with bright accents | Poor legibility or emphasis balance in the actual design | Adjust text/surface/accent relationships; pure black is not inherently forbidden |
| Many accents | Actions and statuses are ambiguous | Assign semantic roles and a clear visual priority; expressive palettes can remain broad |
| Shadow on every surface | Elevation hierarchy is unclear or surfaces become muddy | Define which relationships need shadow, tone, borders, or space |
| Gradient text | Essential text is hard to read across its full range | Improve its least-contrasting region or use solid text for that role |

Do not assert that a particular color combination inherently causes eye strain or proves low quality. Evaluate the actual contrast, reading context, rendering, and brief.

## Typography

| Pattern to inspect | Actual failure signal | Possible correction |
| --- | --- | --- |
| Oversized headings | Required copy wraps awkwardly, dominates the task, or clips | Adjust size/measure/line-height together; preserve intentional display scale |
| Numerous sizes or weights | Equivalent roles look different, or priorities are indistinct | Consolidate roles and make necessary differences meaningful |
| Micro-labels or uppercase | Actual script, font, density, or tone makes them hard to read | Adjust the label treatment for that language and role |
| Thin low-contrast text | Text cannot be read or fails the applicable threshold | Improve the actual contrast/weight/size without arbitrarily requiring one weight |
| Excessive tracking | Word recognition or script shaping suffers | Use the font's natural spacing or a script-appropriate adjustment |
| Manual line breaks everywhere | Copy changes or narrow widths create broken lines | Let the layout wrap; reserve controlled breaks for tested display content |

## Images, data, and proof

| Pattern to inspect | Actual failure signal | Possible correction |
| --- | --- | --- |
| Stock photography | Subject, context, or treatment conflicts with the product | Select more relevant imagery or improve art direction; stock is not inherently unusable |
| Abstract 3D or illustration | It fills space without atmosphere, explanation, or identity | Give it a clear role, choose a more useful asset, or remove the slot |
| Product mockup | Implies nonexistent capabilities or obscures what the product does | Use a real view or clearly label the conceptual demonstration |
| Charts and metrics | Undefined quantities, fabricated data, misleading scales | Use sourced data with context or label sample data visibly |
| Logo wall or testimonial | Relationship/quote is unverified | Use supplied verified material or a different honest form of credibility |
| Generated image artifacts | Distorted details, gibberish text, inconsistent objects, false evidence | Correct or replace the asset; inspect it at final display size |

Never invent trust signals to make a layout feel complete. Attractive sample charts must stay identifiable as examples.

## Motion and interaction

| Pattern to inspect | Actual failure signal | Possible correction |
| --- | --- | --- |
| Every block reveals on scroll | Reading is delayed, content disappears without scripting, or attention has no priority | Keep content available and concentrate motion where it helps |
| Perpetual floating/pulsing | It distracts from reading or causes discomfort | Reduce, stop, or tie it to a meaningful event; provide appropriate controls |
| Parallax | Content becomes difficult to track or performance degrades | Simplify the relationship and offer a reduced-motion alternative |
| Staged intro | Users cannot reach the requested content promptly | Make it skippable/nonblocking or remove it |
| Animated statistics | Animation implies progress or credibility the data does not support | Show an honest value with context; animate only when useful |

## Escape routes that became defaults

Replacing one default with the current counter-default is still autopilot. Treat these as suspects too, and keep them only when the subject and brand call for them:

| Pattern to inspect | Why it counts as a default | Test |
| --- | --- | --- |
| Warm cream background with terracotta or sage accents | The standard "not a SaaS template" palette | Does the palette come from the brand and subject? |
| An italic serif accent word inside every headline | A recurring typographic gesture | Does emphasis serve this sentence? |
| Tiny uppercase eyebrow labels above each heading | Added for texture, rarely read | Would the page lose meaning without them? |
| Monospace labels as decoration, hairline rules, newspaper columns | Editorial costume on non-editorial content | Is the content actually editorial? |
| Arrow glyphs on every link, fade-and-slide on every section, hover lift on every card | Uniform effects with no priority | Does motion mark the single focal change? |
| Black canvas with one acid accent | A swap for purple-on-white | Is contrast and emphasis balanced for this content? |

## Content and finish

Replace vague claims with a specific action, audience, mechanism, or benefit supported by the brief. Label actions by outcome when generic labels would be ambiguous; "Get started" can still work when the next step is clear.

Look for inconsistent use of the same visual role, broken asset fallbacks, misleading states, cramped actual copy, and missing focus treatment. Do not flag a design merely for having several radii, a pill, an emoji, a familiar layout, or a one-off optical adjustment.

After a correction, inspect the composition again. Removal is not automatically improvement: it can erase brand character, explanatory context, or helpful separation.
